# Nook 0.15.0 구현 보고서

작성: 실제 Claude 에이전트 · 검토·교정·취합: Codex · 최종 검토자: 리더

2026-10-14 승인된 두 회의의 구현과 자동 검증을 완료했습니다. 사용자 디자인 검토는 남아 있습니다. 기존 0.14.0을 기준으로 구현하며, 시계 배색은 Claude 의견대로 유지했습니다.

## 구현 결과와 담당

| 범위 | 결과 | 담당 |
|---|---|---|
| 프리셋 복구·Undo | 준비·표시·저장 실패 시 기존 창/배치를 유지, 직전 전환 한 번 되돌리기, 메모 공유/독립과 실행 중 타이머 보호 | Codex · Claude UI |
| 자원 사용 | GPU/디스크 수요별 공유 수집, 숨김/최소화 표시 갱신 제어, 이전 비동기 결과 배제 | Codex · Claude 렌더 |
| 키보드·접근성 | 포커스·접근성 이름, UIA 선택/설정 열기, 볼륨/밝기 범위 조절과 키보드 입력 | Claude · Codex 통합 |
| 우선 디자인 4가지 | 다중 이동 선택 라벨, 설정/숨김/삭제 위계, 메모 공유 옵션 인접 배치, 작은 제목/전체 이름 보존 | Claude · Codex 검토 |
| 선택 디자인 4가지 | 기능별 작은 미리보기, 기능 계열별 본문, 상태/서체 위계, Media/Activity 큰 크기 균형 | Claude · Codex 최종 보완 |

라이브러리는 기존 100 DIP 본문과 34 DIP 미리보기를 사용합니다. 그림은 코드로 그리며 실제 Fluent 아이콘을 재사용합니다. 지표의 막대만 측정값에 연결하고 나머지 그림은 기능을 나타내는 시안입니다. Media 버튼과 진행 막대 간격은 10 DIP입니다. 긴 Activity 기간은 읽을 수 있는 잔디 칸을 유지하며 스크롤합니다.

## 교차 검토와 남은 확인

Claude는 준비 상태의 직접 참조 할당을 검토 우려로 제기했습니다. Codex는 입력을 깊게 복사한 뒤 준비된 모델 소유권을 실제 Settings/ViewModel으로 넘기는 호출 흐름을 설명했고, XML 계약을 추가했습니다. 보존된 Undo 스냅샷을 직접 넘기지 않으며 실패 복구·메모 테스트도 통과했습니다. 초기 우려를 실제 데이터 손상으로 확인한 것은 아닙니다. 논의는 `CLAUDE_REVIEW.md`에 기록했습니다.

실제 물리 모니터 DPI 변경·제거·절전 복귀, 여러 PC의 장시간 성능, 화면 읽기 프로그램의 전체 흐름은 새로 검증하지 않았습니다. QA는 사용자 시작 프로그램·출력 장치·음량·Wi-Fi·전원을 변경하지 않았고, 미디어는 테스트 소유 무음 SMTC 세션만 제어했습니다.

리더는 실행본의 최종 디자인을 검토합니다. 상세 검증은 [VALIDATION.md](VALIDATION.md), 승인 범위는 [APPROVED_IMPROVEMENTS.md](APPROVED_IMPROVEMENTS.md)에 있습니다.
