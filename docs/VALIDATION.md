## 실제 창 검증

`computer-use`로 런타임 포함 배포본을 실행하고 다음을 확인했습니다.

- 실제 CPU·메모리·시각을 표시하는 라이브러리 및 기본 위젯 세 개 생성.
- CPU 제목 드래그 후 위치 저장.
- 투명 모서리에서 리사이즈 입력, Expanded의 실제 최근 추이 그래프, 180×140 Compact 전환.
- 최소 크기에서도 메뉴를 열고 공통 개별 설정 패널로 이동.
- 그룹 생성, 그룹 Radius High 적용, CPU의 그룹 지정 및 적용 출처 표시.
- 메인 창 닫기와 같은 설정 폴더로 중복 실행, 기존 메인 창 ID 유지 및 프로세스 한 개 유지.
- 설정의 종료 버튼을 통한 정상 종료, 종료 오류 로그 없음, 위치·크기·그룹의 JSON 저장과 재실행 시 복원.

일반 실행은 위젯을 ToolWindow로 구성합니다. 직접 위젯을 선택하는 자동화 검증에는 `--inspect-widgets`와 별도 설정 폴더를 사용했습니다.
