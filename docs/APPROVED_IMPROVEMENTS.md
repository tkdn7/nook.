- [2차 회의: 디자인](https://app.notion.com/p/3f8fd84cad7680b4bf1fd488b4f0ff81)

시계 배색은 Claude 의견을 채택해 기존 텍스트 카드의 반전 배색과 원형 아날로그 예외를 유지한다. 크림/검정, 번들 서체, Fluent 아이콘, 테마 분리와 외형 상속을 유지한다.

검색 필터, 내보내기, 프리셋 공유 패키징, 기록 삭제 기능은 이번 구현에 추가하지 않는다. 실제 사용자 설정·자동 실행·음향 출력·전원 설정은 검증에서 변경하지 않는다.

## 검증 원칙

- 프리셋은 실제 HWND를 준비하고, 기존 창을 닫기 전에 표시·저장을 완료한다. 실패 주입으로 기존 창·모델·파일 상태를 검사한다.
- Undo는 한 번만 제공한다. 메모의 공유/독립 의미와 같은 ID의 실행 중 타이머를 보존한다.
- 수집과 렌더를 분리한다. 숨긴 Screen Time·Activity·Key Stats 집계와 countdown은 존재하는 동안 동작을 유지한다.
- GPU·디스크는 단일 서비스가 구독 수요에 따라 수집한다. 숨김/재표시·절전 복귀의 이전 비동기 결과는 새 히스토리에 들어오지 않는다.
- 조회 요청 수와 실제 프로세스 CPU·메모리 측정을 구분한다. 전후 성능 숫자는 같은 시나리오의 측정 결과가 있을 때만 제시한다.
- 두 테마와 크기별 렌더를 검토하고 키보드·자동화 인터페이스를 검사한다. 렌더 배율은 실제 모니터 DPI 변경과 구분한다.

최종 구현·검증 결과는 `VALIDATION.md`에 기록한다. 구현 완료는 리더의 최종 검토 완료와 구분한다.
