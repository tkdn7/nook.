## 에이전트별 의견 및 권고안

### 1. Codex (PM / 디자인·StyleSeed 리드) — 설계 시스템 전략

**StyleSeed 운영 원칙**:
- StyleSeed는 새 스킨 생성기가 아니라 **승인된 Nook 규칙의 전달·증거 관리**에 사용
- **색 권위**: ThemeService만. 생성 palette/recipe HEX는 적용 금지
- **유지할 것**: 크림/검정, 번들 서체(Pretendard/Nunito Sans), Fluent 아이콘, 시계 반전, 본체/위젯 테마 분리
- **바뀔 것**: 위젯의 정보 배치, 비례 패딩, 공간 배분 전략
- **핵심**: 비례 패딩이나 전역 확대만으로는 빈 공간 해결 불가; 그래프·커버·본문에 실제 공간을 배분

**대표3종 확장 전략**:
- **media** (콘텐츠형): 앨범 커버·진행률·시간 메타
- **cpu** (계기형): CPU/Memory/GPU 현재값·추세
- **clock** (시간·원형): 시계 기하와 원형 위젯 출발점
- 각 3종 내 비례 패딩 공식, 정보 위계(Small/Mid/Big), 배경·텍스트·간격 규칙을 먼저 확정
- 이후 Disk/Network/Timer/Memo 등 **가족별 대표 1개**씩만 확장; 25+종 전체 크기×테마×상태 일괄 생산 금지

**규칙 운영**:
- 공통 native 계약 + artifact별 정보/기하 예외 분리
- 승인된 변경만 Codex가 registry/ruleset에 반영
- 컴파일러로 bundle/manifest 갱신 및 짧은 brief와 해시 연동
- Secretary는 artifact ID·brief·bundle 해시·정확한 배정만 전달

**우선순위**:
- **P0**: 토큰/기준 충돌·공개 결함 처리 (소형 Muted 4.40:1 미달, Media 진행률 불일치)
- **P1**: CPU/Clock 전이, Media Dark 실제 산출 먼저 확인; 대표별 긴 콘텐츠·비율·필요 상태 선택 검증 후 가족 단위 확대
- **P2**: Casual/Extend (독립 설계 가능, 수치·상속·프리셋·Undo 보존 critical)
- **P3**: Calendar 이후 Quick Checklist

**신규 위젯**:
- **Calendar**: 로컬 날짜 중심 (외부 계정 없음)
  - Small: 오늘 날짜
  - Mid: 7열 월력, 오늘/선택일 구분
  - Big: 월 탐색·선택일 요약 확장
- **Quick Checklist**: 로컬 목록
  - Small: 미완료 수 + 다음 항목
  - Mid: 짧은 목록 + 간단 입력
  - Big: 더 많은 행, 완료 항목 접기
- 색만으로 선택 구분 금지; 완료는 체크·취소선으로 표시

### 5. Assistant (QA) — 검증 방식 및 증거 기준

**StyleSeed 재현 검증 방식**:
- **입력 고정**: 배정 brief + bundle 해시 + 실제 저장 .pen/PNG/WPF 캡처
- **1 artifact = 1 고유 보고서** (전체 handbook 재검토 없음)
- **증거는 결정적 측정**: PNG bbox·중심·색 core 수치화 (파일·요소·색 증거)

**증거 축 (geometry / text / asset / token / contrast)**:
- **geometry**: 선언 프레임 정확, bbox·간격·정렬, clip 내부, 겹침·잘림·프레임 밖 0
- **text**: 내용·크기·굵기·줄 수, 긴 텍스트 말줄임, 가독성 (Pencil Inter ↔ WPF Pretendard/Nunito 메트릭 차이는 분리 보고)
- **asset**: 승인 도형 재사용 (임의 근사·미지원 아이콘 없음)
- **token**: ThemeService 12 토큰 값 일치, **StyleSeed palette hex 무침입** 확인
- **contrast**: WCAG AA 비 (소형 Muted 4.40:1 미달은 **기록·숨기기 금지**, doctor green 조작 금지)

**대표 vs 확장 프레임 범위**:
- **대표** (media/cpu/clock): 규격·geometry·token·contrast·도형 충실도 **전부** (엄격)
- **확장** (25+ 위젯): **배정 프레임만** (규격·geometry·token·회귀, 새 겹침·잘림 0)
- **상태**: 배정 상태만 (국소 변화·기하 불변)

**한계 (미검증으로 명시)**:
- 정적 PNG/.pen은 실제 WPF 상호작용·키보드/포커스·DPI·라이브 데이터 정확성 증명 불가
- PNG 존재 ≠ 편집 원본 저장 (.pen 빈 skeleton은 실패)
- **수정 예산 1회**; 중요 결함 잔존 시 구현 담당 반환
