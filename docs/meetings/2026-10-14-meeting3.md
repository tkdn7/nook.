## 제안 통합

### 옵션 1: 투명 배경 (Opacity None)

**설계**:
- Opacity 전용 `None` 값 추가 (Level과 분리, Radius는 Low/Mid/High 유지)
- null = 상위 상속 / None = 명시적 배경 투명도 0
- 저장/프리셋: 기존 Low/Mid/High JSON 값 보존, None은 새 enum으로 저장
- 입력 정책: 배경 투명 시 미세 알파 #01000000 활용 (기존 리사이즈 그립), 전체 표면 완전 투명 솔루션은 프로토타입 검증 필요
- 테두리/그림자: 배경 투명 시 제거, 영구 배경 오버레이 없음, 선택/포커스 시에만 단일 임시 포커스 표시
- AQI/Breathe: 기능 그라데이션(콘텐츠)은 유지, 전체 배경 그라데이션 유지 여부는 사용자 승인 대기

**수용 조건**:
- SettingsStore.cs 역호환 검증 (기존 프리셋 로드)
- 투명 배경 위젯 드래그/리사이즈/메뉴 모두 작동 확인 (프로토타입 필요)
- 다크/라이트 테마 양쪽 가독성 검증
- Windows display scaling 100/150/200percent에서 Small/Mid/Big 및 card/circle 검증

### 옵션 2: Activity 기간 선택 통합

**제안**:
- `src/Nook.App/Controls/Widgets/WidgetFeaturesView.Activity.cs` (13-18행) ComboBox 제거
- 기간 선택은 **MyWidgets 개별 설정 패널**에만 유지 (중복 제거)
- 위젯 헤더에는 새 기간 레이블/컨트롤 추가 안 함 (기존 메뉴로 설정 접근)
- 소형 위젯: 기존 최근 7일 규칙 유지 (변경 없음)
- Claude 제안: 헤더에 기간 클릭 시 MyWidgets 로 포커스 이동 (선택사항, 미승인), Codex 반대 의견: 상단 우측 콤보박스 유사 컨트롤 복귀 불가

**Font 폭 조정**:
- `src/Nook.App/Controls/Widgets/WidgetFeaturesView.Activity.cs` 행 20-23의 `header.ActualWidth - 94` DIP 계산은 ComboBox 가정이므로 제거 (DeepSeek 검증 필요)

**수용 조건**:
- MyWidgets에서 기간 변경이 위젯 표시에 즉시 반영
- 저장/프리셋/그룹 복원에서 기간값 유지

### 옵션 3: 마우스 가로 스크롤

**제안**:
- `src/Nook.App/Controls/Widgets/WidgetFeaturesView.Activity.cs`에 `ScrollViewer.PreviewMouseWheel` 핸들러 추가: 휠 델타를 가로 스크롤 오프셋으로 변환
- 휠 단독으로 가로 스크롤 기본 (세로 휠 미지원, Activity 높이는 자동 조정)
- 클릭 드래그 팬: 기본안에서 제외하고 별도 선택 개선으로만 비교; 위젯 이동과 충돌 검증 필요
- 스크롤바 드래그, 트랙패드 가로, 키보드 화살표: 검증 대상 기본 입력 (미검증)

**수용 조건**:
- 마우스 휠로 Activity heatmap 좌우 스크롤 작동
- WidgetWindow 드래그와 이벤트 충돌 없음 (e.Handled=true)
- 수동 히스토리 오프셋은 업데이트 시 자동 점프하지 않음 (행 36-41 ScrollToRightEnd 조건 확인)
- 스크롤바 드래그, 트랙패드, 키보드: 런타임 검증 필요 (현재 미검증)

## 에이전트별 독립 의견 및 피어 리뷰

### Codex (PM)

- Activity 우선 수정 (기간 선택 일원화)
- 마우스 휠 지원, 스크롤바/트랙패드/키보드 병행
- Opacity None은 명시적 값 (null과 구분, Low/Mid/High 의미 보존, Radius와 분리)
- 선택 시 테두리/그림자 제거, 포커스는 최소 편집 표시만 제공
- 실제 상호작용 검증 요구: 휠, 스크롤바 드래그, 트랙패드, 키보드, 경계 동작, 이동/리사이즈/메뉴
- 더 큰 목표: 새 위젯 추가 전 현존 조작 검증 완료 (정지 이미지와 실제 입력은 다른 검증 수준)

### Claude (개발 총책임)

- 기간 ComboBox 제거, MyWidgets 설정으로 통합 동의
- 휠 핸들러 추가 및 키보드 탐색 지원 동의
- 수정: 과도한 배경 오버레이/이중 점선 제거, 단일 포커스 큐만 제공
- 기간 선택 헤더 클릭 바로가기: 선택사항, 미승인 (Codex 반대)
- 배경 히트테스트 보장 불가: 프로토타입 검증 필수

### DeepSeek (보조)

- 모델/저장 호환성 요구-증거 대조표 제공 (`docs/wiki/reports/2026-10-14-meeting3-deepseek.md`)
- Level enum 분리 (None 추가 시 Radius 오염 방지) 동의
- 구버전 JSON 역호환 검증 필수
- 헤더 폭 계산: `header.ActualWidth - 94` DIP은 ComboBox 가정이므로 제거 필요 (행 20-23 검증)
- 수동 히스토리 오프셋: `ScrollToRightEnd` 자동 점프 조건 검토 필요 (행 36-41)
- 미리보기 개선: Settings에서 Opacity ComboBox를 값+배경 알파·모서리 카드 표시 (별도 선택사항, 폭 제약)

### Gemini (위키·증거)

- 현재 코드 사실: 과거 승인 범위 검토 (`docs/wiki/reports/2026-10-14-meeting3-gemini.md` 참조)
- Opacity None: 조회한 승인 문서에서 None 항목은 확인하지 못했으며, 전체 과거 승인 여부로 확대하지 않음
- AQI/Breathe: 기능 그라데이션은 콘텐츠로서 유지하는 안을 권고하되 사용자 판단 대기; None 표면 배경은 제거
- Activity 기간 선택: 현재 코드에서 헤더 우측 콤보박스 있음 (중복 관찰), 과거 승인 문서는 미검증
- 투명 배경 히트테스트: 기존 #01000000 미세 알파 활용, 전체 표면은 미검증
- 가장자리 페이드/스크롤 화살표: 별도 선택사항 (사용성 개선)
