## 제안 통합

### 안 A: 위젯 반응형 Relative 레이아웃 및 빈 공간 최소화

**설계**:
- 고정 패딩(16,10,16,12)을 비례 패딩(4–5% 최소 축)으로 대체
- 제목/아이콘 영역 확보(28–32px) + 바닥글(자동 높이)
- 남은 공간을 주 콘텐츠(그래프/커버/메모 본문)에 배분
- 비대칭 리사이즈(예: 640×140 가로): 보조 정보(막대, 범례) 축소 후 Big 레이아웃 강제 금지

**실현성**:
- 비례 패딩 공식은 원형(Circle) 위젯에 직접 적용 불가; CircularLayoutPanel 별도 처리
- 내용이 제한적인 위젯(Key Stats)은 기존 최대 크기 제한 유지
- ContentScaleFactor 전역 정책(0.8/1.0/1.2) 미채택 (Codex 교정): 각 모드 내 콘텐츠별 연속 확장, 글자/버튼은 읽기성 상한 유지

**수용 조건**:
- CPU/Memory/GPU, Media, Clock/Timer 대표 위젯의 Small/Mid/Big 시안 검증
- 비대칭 모드 분기 임계값(640×140) 확정
- 원형 패딩 공식 별도 설계 확인

### 안 B: 설정 Casual/Extend 분리 설계

**모델 아키텍처**:
- 3단계 상속: 개별 → 그룹 → 전체
- Casual 모드(현행): Level enum (Low/Mid/High), 완전 역호환
- Extend 모드(선택): 수치 슬라이더 — Radius 0–32 DIP (1 DIP 단위), Opacity 0–100% (1% 단위)

**critical 규칙** (Codex 교정):
- **모드 전환 시 수치 삭제/반올림 금지**: Extend 73% 편집 → Casual 전환(Mid 82% 표시) → Extend 복귀 → 73% 그대로 복구
- 우선순위: 개별 수치 > 개별 enum > 그룹 > 전체
- 개별 enum 명시 선택 시 해당 속성의 수치만 삭제; 상위 따르기 해제 시 enum/수치 함께 해제; 다른 속성/그룹은 유지
- None(0%)은 현행 정책(테두리/그림자 제거)과 연결, 글자/아이콘/기능 그라데이션은 유지

**저장 및 검증** (`SettingsStore.cs:74–84, 126–127`):
- 레거시 프리셋 로드: Extend 모드 active 시 enum → 수치 동등값 변환
- 저장 검사: Radius 0–32 DIP, Opacity 0–100%, 개별/그룹/전체 계산 우선순위 일치
- Undo/복귀: 슬라이더 드래그 한 번 = 한 개 Undo 항목 (매 프레임 아님)

**수용 조건**:
- Casual ↔ Extend 모드 전환 시 기존 사용자 정의 수치 완전 보존
- 프리셋과 편집 모드 분리 (프리셋은 외형값+재정의, 편집 모드는 앱 환경설정)
- 모드 전환만으로 렌더링/저장값 정책 변경 금지

### 안 C: 신규 위젯 기회

**평가 대상** (12개 아이디어):
- 높은 실현성 (Phase 1 후보): World Clock (BCL TimeZoneInfo), Drive Capacity (BCL DriveInfo), Uptime (Environment.TickCount64), D-day (사용자 입력), Habit Check (SettingsStore 재사용)

**PM 독립 후보**:

## 구현 후 검증 항목

다음은 프로토타입 빌드·시각 렌더링을 거쳐야 하는 미검증 항목:

- **비례 패딩 시각 균형**: 4–5% 공식이 실제 위젯 크기에서 균형 맞는지 미검증, 조정 필요 가능
- **차트 높이 확대**: clamp `height-190` → 48–220 DIP는 코드 사실; 640×480, 180×480 동작 미검증
- **비대칭 모드 분기**: 640×140 가로 임계값 미확정, 중간 breakpoint 필요 가능
- **Casual↔Extend 전환 UX**: 수치와 enum 동시 표시("Mid(82%) / 사용자 73% 저장") 프로토타입 미실행
- **원형 위젯 패딩**: Clock/Timer/메트릭 원형은 CircularLayoutPanel, 카드 패딩 공식 미적용; 적응 미검증
- **Opacity 0% 렌더링**: 완전 투명 표면에 글자/아이콘 가시성 시각 미확인
- **프리셋 전후 호환성**: Extend로 만든 프리셋을 Casual에서 로드 시 폴백 로직 미실행
- **고DPI 렌더링**: 150%, 200% DPI에서 clamp 차트 높이 동작 미테스트
- **모든 위젯 Big 크기**: 대표 위젯(CPU/Media/Clock)만 분석; Memo/Shelf/Pomodoro/등 미검증
- **Undo/저장 성능**: 수치 편집 빈도, Undo 스택 깊이, 저장 검증 비용 미프로파일
- **접근성(키보드/스크린리더)**: 슬라이더 입력, 모드 전환 포커스/라벨 미평가
