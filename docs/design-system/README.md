# Nook 디자인 시스템 (공유)

사람이 검토한 색·간격·타이포그래피·컴포넌트 계약과 출처를 담는 **공유 위치**입니다. 개인의 StyleSeed/Impeccable 설치와 개인 디자인 작업 로그는 공유하지 않으며, 제품에 필요한 승인 기준만 이 위치로 내보냅니다.

상태 표기: **approved**(사람 승인) / **candidate**(미승인 후보) / **gate**(사람 결정 대기).

## 승인된 방향 (approved, 사람 결정)
- **P4 "Midnight Violet" 팔레트** (2026-10-15, MEETING-6): `#160C28` `#297373` `#E1EFE6` `#AEB7B3` `#000411`.
- **투명도 유지 + 블러 요구**: 표면 투명은 유지하고 배경 블러는 필수. 단 **실제 Windows/DWM 블러 구현은 아직 검증되지 않은 열린 게이트**입니다(PoC-A). 저작 도구의 `background_blur`는 실제 블러가 아닙니다.
- **테마 토큰 권위**: `ThemeService` 토큰이 기준이며, 파생/뉴트럴 색은 디자인 리드 재량. 엔진이 생성한 팔레트를 그대로 제품에 가져오지 않습니다.
- 기존 대표 시안은 자동 일괄 치환하지 않고 별도 Theme 설정으로 분리합니다.

## 후보 (candidate, 미승인 — 참고만)
- **CPU v3 rev02** 게이지/히스토그램: 기계적 QA 통과, **사용자 채택 대기**.
- **미디어 전송부(transport)**: 공통 표면 High 0.96 + Pine + BT1/BT2 버튼. StyleSeed 승격은 디스패치용으로 채택됨. 최종 팔레트 선택은 사람 대기.

## 주의 (standing cautions)
- 워크플로/QA 통과는 **사용자 디자인 승인이 아닙니다.**
- 저작 픽스처 블러 ≠ 실제 Windows/DWM 블러. 일부 `.pen`의 한글은 편집 가능한 텍스트가 아니라 글리프 아웃라인입니다.
- 저작권/개인정보가 있는 스크린샷·폰트·디자인 파일은 사람이 검토한 뒤에만 공유합니다.
