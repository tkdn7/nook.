# 디자인 원칙

1. **대표 우선(representative-first)**: 사람이 승인한 대표 시안을 먼저 확정하고, 그 다음에 변형·복제를 진행합니다.
2. **단일 디자인 리뷰**: 재료 시각 방향은 디자인 리드가 1회 검토합니다. 워크플로/QA 통과는 승인이 아닙니다.
3. **실물 검증**: 정지 렌더가 아니라 실제 PNG/`.pen`의 경계·겹침·정렬·자산, 그리고 상호작용(마우스/키보드)을 확인합니다.
4. **토큰 권위**: 제품 기준은 `ThemeService` 토큰. 생성 팔레트는 참고만.
5. **개인 도구 비공유**: 개인의 StyleSeed/Impeccable 설치·설정은 공유하지 않고, 승인된 제품 기준만 이 디렉터리로 내보냅니다.
6. **저작권/개인정보**: 외부 폰트·이미지·스크린샷은 사람이 검토한 항목만 공유합니다.
