# Nook 0.15.0

Windows 11 x64용 WPF 위젯 프로토타입입니다. Soft Desk의 크림 `#F6F0E6`·블랙, Pretendard·Nunito Sans, Microsoft Fluent System Icons를 사용합니다.

## 실행과 공유

`artifacts/releases/Nook-15.0-win-x64.zip`을 풀고 `Nook.exe`를 실행합니다. .NET 런타임을 포함하므로 별도 설치 없이 사용할 수 있습니다. 친구와 실행본만 공유하려면 이 ZIP을 전달하세요. 소스 작업용 ZIP은 `Nook-15.0-source.zip`입니다.

개발은 Windows와 .NET 10 SDK가 필요합니다. 저장소의 `Nook.slnx`를 열거나 PowerShell에서 실행합니다. `.tools/dotnet`이 있으면 스크립트가 해당 SDK를 사용하며, 없으면 PATH의 `dotnet`을 사용합니다.

```powershell
./scripts/run.ps1
./scripts/build.ps1
./scripts/publish.ps1
./scripts/source.ps1
```

격리한 설정으로 실행하려면 `./scripts/run.ps1 -SettingsDir artifacts/demo-settings` 또는 `Nook.exe --settings-dir <폴더>`를 사용하세요. 일반 실행의 설정·메모는 `%LocalAppData%/Nook`에 보관합니다.

## 0.15.0 변경

- **프리셋 복구·Undo:** 새 창을 준비한 뒤 배치를 전환합니다. 준비·표시·저장에 실패하면 기존 배치와 창을 유지하고 원인을 표시합니다. 프리셋 화면의 `되돌리기`는 직전 전환 한 번을 되돌립니다. 공유 메모의 최신 내용과 같은 ID의 실행 중 타이머, 사용 기록, 본체 설정을 보존합니다. 독립 메모는 원래 프리셋의 내용으로 복원합니다.
- **수집과 렌더:** GPU·디스크는 보이는 위젯이나 라이브러리 미리보기가 필요할 때만 공유 수집합니다. 숨김 위젯의 표시 갱신은 줄이되 사용 시간·타자 기록과 타이머는 계속 유지합니다. 디지털 시계·멈춘 타이머는 연속 프레임을 사용하지 않습니다.
- **키보드·접근성:** 탐색·설정·메뉴와 스위치의 키보드 포커스를 유지합니다. 볼륨·밝기는 방향키(1), Page Up/Down(10), Home/End(최소/최대)와 UI Automation 범위 조절을 지원합니다. 실제 하드웨어에서 지원하지 않는 조절은 읽기 전용으로 취급합니다.
- **화면 구성:** 내 위젯의 다중 이동 선택을 구분하고 설정을 주동작으로 제공합니다. 삭제는 `…` 메뉴로 옮겼습니다. 프리셋의 메모 공유 라벨과 토글을 함께 배치했습니다. 작은 위젯은 짧은 제목을 사용하며 전체 이름과 사용자 이름을 유지합니다.
- **기능별 미리보기·본문:** 라이브러리는 작은 기능별 그림을 사용합니다. Media의 커버·곡 정보·재생 조작, Activity의 기간·잔디·범례가 공간에 맞게 배치됩니다. 크림/검정·서체·Fluent 아이콘·공통 외곽 조작은 유지하며, 시계의 기존 반전 배색과 원형 아날로그 예외도 유지합니다.

승인 범위와 역할은 [개선 작업 문서](docs/APPROVED_IMPROVEMENTS.md), 실행한 검사와 남은 검토 범위는 [검증 기록](docs/VALIDATION.md)에 있습니다. 최종 디자인 판단은 리더 검토를 거칩니다.

## 0.14.0 변경

- **Screen Time:** 설정의 `Screen Time에서 Nook 제외`로 집계와 기존 기록의 표시에서 Nook을 제외합니다. 기존 기록은 삭제하지 않으므로 다시 끄면 이전 기록을 확인할 수 있습니다. 비율은 제외 후 다시 계산합니다. 원형은 Timer·Pomodoro와 같은 얇은 240도 게이지를 사용하며 제목과 겹치지 않습니다.
- **Dice:** 더 작은 기본 크기 260×170 DIP로 생성하며 가로·세로 배치를 지원합니다. 최대 긴 변 420, 짧은 변 280 DIP, 종횡비 1:2~2:1 안에서 자유롭게 조절합니다. 메뉴의 가로/세로 Small·Mid·Big 프리셋, 드래그·Magnetic Mode·직접 창 크기 변경·복원에 같은 제한을 적용합니다.
- **Volume / Brightness:** 원형은 Timer·Pomodoro의 게이지·중앙 값·여백을 공유합니다. 게이지를 드래그하면 값, 중앙·빈 공간을 드래그하면 위치, 원 둘레를 드래그하면 크기를 바꿉니다.
- **System Shelf:** 클릭한 ON/OFF 상태를 즉시 표시합니다. 작업 중 중복 클릭을 막고 실제 결과로 확인하며 실패하면 이전 상태로 돌아갑니다. 다른 System Shelf에도 함께 반영합니다.
- **Media:** Visualizer 설정·렌더링·음량 수집기를 제거했습니다. 앨범 커버와 재생·이전·다음·진행 정보는 유지합니다.
- **Memo:** 최상단 좌측에서 입력하고 포커스 테두리를 제거했습니다. 메모 내용은 자동 저장합니다.
- **Activity:** 개별 설정의 `오늘 사용 시간 표시`를 끄면 좌측 상단의 시간만 숨깁니다. Small은 최근 7일, Mid는 선택한 기간, Big은 요일·월·색상 범례를 표시합니다. 긴 기간은 알아볼 수 있는 칸 크기를 유지하며 가로 스크롤합니다. 실제 Screen Time 기록을 공유하고 임의 데이터를 생성하지 않습니다.
- **Key Stats:** 제목과 전체 타자 수만 표시합니다. 보조 문구를 제거하고 180×140~220×160 DIP의 Small 크기로 제한합니다. 기본 크기는 200×150 DIP입니다. 자주 쓰는 키 기능과 키별 영구 저장은 제거했습니다. 이전 키별 기록은 누적 총합으로 이전합니다. 자동 반복·주입 입력·Shift/Ctrl/Alt/Windows 키는 제외합니다.
- **본체:** 라이브러리를 작은 카드와 간결한 아이콘·설명·추가 버튼으로 구성했습니다. 기본 위젯 묶음 추가 버튼은 제거했습니다. 내 위젯의 전체/그룹별/태그별 보기를 제공하고 태그는 기존 시스템·일상·도구·집중·놀이 분류입니다. 우측 상단 `그룹 추가`는 모달로 열립니다. 대각선 크기 조절 영역을 넓히고 외형은 유지했습니다.
- **프리셋:** 독립된 `프리셋` 메뉴에서 현재 위젯 종류·위치·크기·표시·그룹·외형·위젯 옵션을 저장·적용·이름 변경·덮어쓰기·삭제합니다. 프로그램 본체 테마와 사용 기록은 전환으로 되돌리지 않습니다.

- **원형 아날로그 시계:** 시계판이 원형 표면의 약 93%를 사용하며 12개 눈금과 가늘게 끝나는 시침·분침을 표시합니다. 분침은 시침보다 살짝 연합니다. 제목은 숨기고 `…` 메뉴는 호버/포커스 시 접근할 수 있습니다. 개별 라이트·다크 테마를 따릅니다.
- **토글:** 본체의 선택·잠금·설정·프리셋 메모 공유 옵션은 Magnetic Mode와 같은 스위치 형태를 사용합니다.
- **시작 프로그램:** 최초 일반 실행에서 로그인 시 자동 실행을 권유합니다. `자동 실행 켜기`를 선택한 경우에만 현재 사용자에게 등록합니다. 설정에서 언제든 끌 수 있으며, 로그인 시에는 본체를 트레이에 숨기고 위젯을 복원합니다. 실행 폴더를 옮겼다면 설정을 껐다 켜 새 위치로 등록하세요. 격리 설정으로 실행하는 QA/데모에서는 등록하지 않습니다. 관리자 권한을 요구하지 않는 [Windows Run 등록](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys)을 사용합니다.

## 새 위젯

**Breathe**는 카드·원형의 크기에 맞춰 부드러운 그라데이션이 2초 동안 넓어지고 2.5초 동안 좁아지는 시각 위젯입니다. 개별 설정에서 Sky·Lavender·Mint·Peach 색상을 선택합니다. 숨김 상태에서는 움직임을 멈추고 복원 시 이어갑니다. Windows 모션 OFF에서는 정적인 그라데이션을 표시합니다. 센서나 API를 사용하지 않습니다.

**Media Controller**의 `볼륨 슬라이더 표시`를 켜면 하단에 기본 출력 볼륨을 조절하는 얇은 가로 스틱이 나타납니다. 기본은 OFF입니다. 연결된 음향 출력 장치를 표시하고 선택한 장치를 Windows 기본 출력으로 바꿉니다. 일반·미디어·통신 기본 출력에 적용합니다. 앱 자체가 특정 장치에 고정되어 있으면 Windows 기본값을 따르지 않을 수 있습니다. 연결 해제와 전환 실패를 처리하고 목록을 자동 또는 수동 갱신합니다. 네이티브 구현과 검증 범위는 [출력 장치 문서](docs/AUDIO_OUTPUT.md)에 있습니다.

**Calculator**는 기본 300×400 DIP, 최소 240×300 DIP입니다. 넓고 높은 크기(약 404×357 DIP 이상)에서 공학 키패드를 표시합니다. `sin/cos/tan`, `asin/acos/atan`, `sqrt`, `ln/log`, `abs/exp`, `pi/e`, `Ans`, `^`, `!`, `%`, 괄호를 지원합니다. 공학 모드에서 DEG/RAD를 선택하고 키보드로 식을 입력할 수 있습니다. `%`는 바로 앞 값의 백분율입니다. Enter로 확정하고 Escape로 비웁니다.

`메모로 보내기`는 입력한 식과 결과를 한 줄로 추가합니다. Memo가 하나이면 바로 전송하고 여러 개이면 Calculator의 개별 설정 `계산 결과를 보낼 메모`에서 선택합니다. 대상이 없으면 설정을 열어 선택하도록 합니다.

## 프리셋의 메모

기본은 프리셋별 내용 보관입니다. 전환해도 해당 프리셋에서 편집한 메모를 다시 불러올 수 있습니다. 프리셋마다 `메모 내용 공유`를 켜면 **동일한 ID의 메모 위젯**을 다른 공유 프리셋과 함께 사용합니다. 같은 배치에서 프리셋을 여러 개 저장하면 메모 ID를 유지합니다. 별도로 새로 추가한 메모는 독립된 위젯입니다.

배치 변경은 `현재 배치로 덮어쓰기` 또는 새 프리셋 저장으로 반영합니다. 메모 내용은 자동 저장하고 Screen Time·Activity·타자 기록은 프리셋과 별도로 계속 보관합니다. 프리셋 적용으로 본체 테마를 변경하지 않습니다.

## 기본 조작과 시연

1. 라이브러리에서 위젯을 추가합니다. 동일 종류도 여러 개 만들 수 있습니다.
2. 제목을 드래그하고 가장자리·모서리로 크기를 조절합니다. `…`에서 크기 프리셋·모양·개별 설정·잠금·숨김·삭제를 사용합니다.
3. 설정에서 Magnetic Mode를 켜 이웃과 간격을 맞춥니다. Shift를 누르는 동안 해제합니다. Ctrl+클릭 또는 내 위젯의 선택 토글로 여러 위젯을 선택해 함께 이동합니다. Esc로 선택을 해제합니다.
4. 그룹을 만들고 위젯을 배정합니다. 모서리·배경 불투명도는 개별 → 그룹 → 전체 순서로 상속합니다. 본체 테마와 위젯 기본/개별 테마는 독립적입니다.
5. 배치를 프리셋 두 개로 저장하고 메모 내용 공유를 켜거나 끈 상태에서 전환합니다.
6. Calculator를 작은/큰 크기로 바꾸고 결과를 Memo로 보냅니다. Media Controller에서 장치 목록을 확인합니다.
7. 종료 후 다시 실행해 배치·메모·프리셋을 확인합니다.

본체를 닫으면 트레이로 숨겨지며 위젯은 동작합니다. 트레이에서 열기·전체 표시/숨김·종료를 사용합니다. Win+D에서도 남는 바탕화면 부착은 구현 범위에 포함하지 않습니다.

## 다른 위젯과 데이터

CPU·Memory·GPU·Disk·Network·Battery·Bluetooth는 실제 Windows 데이터를 사용합니다. CPU는 논리 프로세서 64개 이하 PC를 검증 대상으로 합니다. Clock·Pomodoro·Timer, Program Shelf·System Shelf, Memo·Dice를 지원합니다. Weather는 샘플 날씨이고 Air Quality는 API 없이 개별 설정에서 모든 대기질 단계를 선택하는 시연용입니다. 고양이 위젯은 제거된 상태를 유지하며 이전 설정의 고양이 항목만 제외합니다.

Screen Time/Activity는 Nook 실행 중 해당 위젯이 존재할 때 앞에 열린 앱을 집계합니다. 잠금·절전·입력 유휴 5분 이상은 제외합니다. 설치 전 기록을 복원하지 않습니다. Key Stats도 해당 위젯이 존재할 때만 집계하며 문자 내용·입력 순서를 저장하지 않습니다.

## 소스와 검증

- `src/Nook.Core`: 저장 모델, 상속·크기 규칙, 계산 엔진, 프리셋과 사용 기록.
- `src/Nook.App`: `Views`, `ViewModels`, `Services`, `Controls/Widgets`, `Themes`, `Assets`.
- `tests`: 핵심 로직과 실제 WPF·Windows 검증.
- `scripts`: 실행·검증·패키징. `artifacts/releases`는 실행본과 ZIP, `artifacts/qa`는 검증 결과입니다.

검증 결과와 하드웨어 제한은 [검증 기록](docs/VALIDATION.md)을 참고하세요. 100/150/200% 검사는 렌더 배율이며 물리 모니터 배율 변경과 구분합니다. Bluetooth·밝기·Wi-Fi 등은 지원 장치와 Windows 권한에 따라 사용할 수 없습니다.

폰트와 Fluent System Icons의 라이선스는 실행본의 `docs/licenses`에 포함합니다. [Pretendard](https://github.com/orioncactus/pretendard), [Nunito Sans](https://github.com/googlefonts/nunito-sans), [Fluent System Icons](https://github.com/microsoft/fluentui-system-icons).
