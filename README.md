# Nook

Windows 11의 바탕화면에 CPU, Memory, GPU, Clock, 데모 날씨 위젯을 자유롭게 배치하는 시연 프로토타입입니다.

0.6은 **Soft Desk / Cream & Black** 디자인입니다. 화이트 역할의 색상을 `#F6F0E6`으로 변경했습니다. 시계와 CPU·메모리·GPU·날씨 카드, 번들 Pretendard·Nunito Sans 글꼴, 크림·블랙 라이트·다크 테마를 실제 앱과 위젯에 적용했습니다. Magnetic Mode 스위치는 설정에만 표시합니다. 디자인 기준과 Mobbin 참고 화면은 `DESIGN_DIRECTIONS.md`에 정리했습니다.

## 0.6 변경

- CPU·Memory·GPU의 **내 위젯 → 설정 → 모양**에서 카드 / 원형을 선택합니다. Clock·날씨에는 모양 선택이 없습니다.
- 원형은 중앙 사용률과 하단 120° 곡선 막대를 사용합니다. 수치는 실제 측정값이며 막대는 360ms로 갱신됩니다. Memory는 Mid 이상에서 사용/전체 용량도 표시합니다. 원형에는 60초 그래프를 표시하지 않습니다.
- 원형 표면을 드래그해 이동하고 원 둘레의 상하좌우·대각선 영역에서 크기를 조절합니다. 지름은 180~480 DIP이며 비율을 유지합니다. 크기 메뉴는 Small 220 / Mid 300 / Big 420 DIP입니다.
- 원형 모양과 크기는 저장·복원됩니다. 색상 테마와 배경 불투명도는 기존 설정을 따릅니다. 원형에서는 모서리 옵션을 비활성화하며 기존 지정값은 카드로 돌아올 때 다시 적용됩니다. 모양은 그룹/전체 설정과 별개인 개별 선택입니다.

## 0.5.1 변경

- Magnetic Mode는 드래그 시작 위치와 포인터 이동량을 기준으로 처리합니다. 보정된 창 위치가 다음 이동에 누적되지 않으며 6 DIP를 벗어나면 바로 풀립니다. Shift를 누르고 드래그하면 일시적으로 자유 이동합니다.
- 내 위젯의 스크롤 바는 화살표와 배경 트랙을 제거하고 얇은 둥근 손잡이를 사용합니다. 라이트·다크를 따르며 드래그와 트랙 클릭을 지원합니다.
- 감성 슬로건, 디자인 테마명, 변경 요구사항을 설명하던 문구를 화면에서 제거했습니다. 설정 이름·현재 적용 출처·측정 오류·샘플 날씨 안내는 유지합니다.

## 0.5 변경

- 위젯별 테마: 전체 테마 따르기 / Windows 설정 / 라이트 / 다크. 개별 선택은 전체 테마 변경과 그룹 변경에도 유지하고 재실행 시 복원합니다. 그룹은 Radius·Opacity만 공유합니다.
- 위젯의 Mid·Big 배지와 GPU 엔진 설명을 제거했습니다. Small·Mid·Big 레이아웃 및 크기 메뉴는 유지합니다.
- 내 위젯의 설정 버튼은 해당 카드 안을 펼칩니다. 다른 위젯이나 그룹을 열면 이전 카드는 접힙니다. 설정 변경이 카드를 새로 만들거나 페이지 맨 아래로 이동시키지 않습니다.
- 카드 확장/접힘 220~260ms, 화면 진입/위젯 표시 180~240ms, 숨김 140ms, 사용량 막대 360ms, 크기 프리셋 260ms의 모션을 사용합니다. 버튼과 토글, 반응형 정보 전환에도 짧은 모션을 적용합니다.
- 애니메이션 중 다시 열기·닫기·크기 조절을 하면 현재 상태에서 이어서 처리합니다. 마우스 드래그와 가장자리 리사이즈는 즉시 입력을 따릅니다. Windows에서 UI 애니메이션을 끄면 모션을 생략합니다.

## 실행

배포 ZIP을 풀고 포함된 폴더의 `Nook.exe`를 실행하세요. 0.6 패키지의 폴더 이름은 `Nook-06-win-x64`입니다. 기존 Nook이 실행 중이면 설정 또는 트레이의 종료로 완전히 닫은 뒤 실행하세요. **폴더 전체가 필요합니다.** .NET 런타임은 포함되어 있습니다. 대상 환경은 Windows 11 x64입니다.

- 라이브러리에서 개별 위젯 또는 **기본 위젯 3개 추가**를 선택합니다.
- 위젯 제목을 드래그해 이동하고, 가장자리/모서리를 드래그해 크기를 조절합니다.
- **설정 → 배치 → Magnetic Mode 스위치**에서 ON/OFF를 선택합니다. ON에서는 드래그 중 가까운 위젯의 가장자리와 16 DIP 간격, 두 위젯 사이의 같은 간격에 붙습니다. 빈 공간에서는 자유롭게 움직이고 크기와 잠금 상태는 바꾸지 않습니다. OFF는 자유 배치입니다. 설정은 재실행 후에도 유지됩니다. 기존 0.2·0.3 설정과 호환하도록 JSON의 AutoGrid 키를 유지합니다. 키보드 Tab으로 스위치에 이동하고 Space로 전환할 수 있습니다.
- 위젯에 마우스를 올리거나 Tab으로 포커스를 주면 `⋯` 메뉴가 표시됩니다.
- 메인 창을 닫으면 트레이에 남습니다. 트레이 메뉴의 **종료** 또는 설정의 **Nook 종료**로 완전히 종료합니다.
- 트레이의 **Nook 열기**, 또는 프로그램 재실행으로 메인 창을 다시 엽니다.
- 기본 위젯은 일반 창 뒤에 가려지며 Win+D에서 숨겨질 수 있습니다. 설정에서 **항상 위에 표시**를 선택할 수 있습니다.

## 시연 순서

1. 라이브러리 → **기본 위젯 3개 추가**.
2. 각 제목을 드래그해 배치하고, CPU 위젯을 작게/크게 조절합니다.
   **설정 → 배치**에서 Magnetic Mode를 켜고 다른 위젯 옆으로 이동해 정렬을 확인한 다음 OFF로 자유 이동을 비교합니다.
3. 너비 360 DIP, 높이 260 DIP 이상에서 최근 60초 그래프가 나타납니다. 초기에는 수집된 구간만 표시됩니다.
4. **내 위젯** → `시스템 모니터` 그룹을 만들고 CPU·Memory의 설정에서 해당 그룹을 지정합니다.
5. 그룹 Radius를 High, Opacity를 Mid로 변경합니다.
6. CPU만 개별 Radius를 Low로 지정합니다.
7. **설정**에서 전체 Radius를 변경합니다. CPU 개별 값과 Memory 그룹 값이 유지되는지 확인합니다.
8. CPU의 **상위 설정으로 초기화**로 그룹 외형을 다시 따르게 합니다.
9. 트레이에서 종료 후 재실행하여 배치와 설정 복원을 확인합니다.

## 크기와 외형

크기 범위는 180×140 ~ 640×480 DIP이며 최초 크기는 300×200입니다. 위치는 물리 화면 좌표, 크기는 DIP로 저장합니다.

| 레이아웃 | 조건 | 표현 |
|---|---|---|
| Small | 아래 조건 미충족 | 현재 수치 / 시·분 |
| Mid | 너비 ≥ 280, 높이 ≥ 180 | 막대와 상세 용량 / 날짜 / 날씨와 최고·최저 |
| Big | 너비 ≥ 360, 높이 ≥ 260 | 최근 60초 그래프와 평균·최고 / 초·요일 / 시간대별 예보 |

메뉴에서 Small 220×160 / Mid 300×200 / Big 420×310을 빠르게 선택할 수 있습니다. 가장자리 드래그는 연속 크기 조절입니다.

축소 시 8 DIP 여유를 두어 경계에서 전환이 반복되지 않게 합니다. 단순 확대가 아닌 정보량과 배치 변경 방식입니다.

- Radius: Low 8 / Mid 16 / High 24 DIP. 기본 Mid.
- Opacity: Low 65% / Mid 82% / High 96%. 기본 High. **배경만** 변경됩니다.
- 외형 우선순위는 **개별 > 그룹 > 전체**이며 Radius와 Opacity가 독립적으로 상속됩니다. 테마는 **개별 위젯 > 전체**로 결정하며, 개별 Windows 설정은 앱 테마와 독립적으로 시스템을 따릅니다.
- 위젯은 그룹 하나에 속하며 그룹은 외형만 공유합니다. 그룹 삭제 시 위젯과 개별 지정값은 유지됩니다.
- 시스템·라이트·다크 테마를 지원합니다. 배경 블러는 적용하지 않습니다.
- 시계는 라이트 테마에서 검은 표면, 다크 테마에서 밝은 표면으로 대비를 줍니다. CPU·메모리·GPU·날씨는 해당 테마의 기본 표면을 사용합니다. 모든 위젯의 Radius·Opacity 상속은 그대로 적용됩니다.
- 글꼴과 OFL 라이선스는 앱에 포함되어 별도 글꼴 설치나 인터넷 연결이 필요하지 않습니다.

모든 직접 작성한 UI 아이콘과 앱·트레이 아이콘은 [Microsoft Fluent UI System Icons](https://github.com/microsoft/fluentui-system-icons)의 Regular SVG를 사용합니다. 테마 색상과 크기만 조정하며 원본 SVG와 MIT 라이선스를 배포 폴더에 포함합니다. Windows의 기본 창 제목 표시줄은 OS가 그립니다.

## 데이터와 저장

Magnetic Mode는 드래그 중 위치만 조정합니다. 활성화할 때 기존 배치를 이동하지 않고, 크기도 격자에 강제로 맞추지 않습니다. 가까운 위젯/작업 영역 가장자리에 6 DIP 이내로 접근하면 붙습니다. 보이는 위젯만 정렬 대상으로 사용하며 잠긴 위젯도 다른 위젯의 정렬 기준이 될 수 있습니다. 멀리 떨어진 행·열과 다른 모니터의 위젯은 정렬 대상에서 제외합니다. 작업 영역 가장자리에서도 6 DIP 이내일 때만 붙으며, 그 외 위치는 강제로 보정하지 않습니다.

CPU는 `GetSystemTimes`, Memory는 `GlobalMemoryStatusEx`를 통해 PC 전체의 실제 데이터를 1초마다 한 번 수집합니다. 그래프는 최근 60초의 측정값만 담습니다. 시계는 PC 로컬 시간대, 24시간제를 사용합니다.

GPU는 Windows PDH의 `GPU Engine(*)\Utilization Percentage`를 공유 쿼리로 수집합니다. 프로세스별 값을 같은 GPU 엔진끼리 합산한 뒤 가장 바쁜 엔진의 사용률을 표시합니다. 여러 GPU가 있으면 전체 GPU 중 가장 바쁜 엔진을 표시하며 특정 GPU 선택은 이번 범위에 포함하지 않습니다. WDDM GPU 카운터가 없는 환경은 `—`와 측정 불가 안내를 표시하고 15초마다 다시 연결합니다. GPU 수집은 백그라운드에서 수행합니다.

날씨는 서울 22°, 구름 조금이라는 고정 데모 데이터입니다. 위치 검색, 실제 예보, API 또는 위치 권한은 사용하지 않습니다. 모든 크기에서 데모임을 표시합니다.

설정은 `%LocalAppData%/Nook/settings.json`에 저장합니다. 임시 파일을 기록한 뒤 교체합니다. 손상된 파일은 `settings.invalid-*.json`으로 보관하고 기본값으로 시작합니다. 저장에 실패하면 메인 화면에 안내합니다. 치명적 오류는 같은 폴더의 `errors.log`에 기록됩니다.

다른 설정 폴더로 실행하려면:

```powershell
./Nook.exe --settings-dir 'C:/path/to/nook-demo-settings'
```

## 개발과 빌드

필요 도구: .NET 10 SDK. 프로젝트 안의 `.tools/dotnet/dotnet.exe`가 있으면 스크립트가 우선 사용하고, 없으면 PATH의 `dotnet`을 사용합니다.

```powershell
# 빌드 및 핵심 로직 테스트
./scripts/build.ps1

# 런타임 포함 배포 폴더와 ZIP 생성
./scripts/build.ps1 -Publish

# 개발 실행
./scripts/run.ps1
```

출력: `artifacts/Nook-win-x64/`, `artifacts/Nook-win-x64.zip`.

구조: `src/Nook.Core`는 모델·상속·CPU 계산·레이아웃·저장, `src/Nook.App`은 WPF 뷰·뷰모델·창/트레이·Windows API 서비스, `tests/Nook.Tests`는 핵심 로직 테스트, `tests/Nook.UiTests`는 WPF 렌더링 테스트입니다. 테스트는 외부 프레임워크 패키지 없이 실행하며 `dotnet run --project <테스트 프로젝트>`를 사용합니다. IDE에서는 `Nook.slnx`를 열면 됩니다.

UI 자동화 도구에서 위젯 창을 직접 검사해야 할 때는 `--inspect-widgets`를 추가합니다. **이 검증 모드에서만** 위젯이 작업 표시줄과 Alt+Tab에 나타납니다. 일반 실행에는 이 옵션을 사용하지 않습니다.

## 검증 범위

자동 테스트는 속성별 상속·그룹 변경/삭제·초기화, 반응형 경계, CPU 초기/유휴/부하/잘못된 시간 차이, 기록 만료, 모니터 작업 영역 보정, 저장 복원/손상/잘못된 설정을 검증합니다.

핵심 로직 테스트 24건, 라이트·다크 / 다섯 크기 / 세 렌더 배율, 5종 위젯 렌더링·메인 페이지·설정 스위치·원형 위젯의 라이트/다크·다섯 지름·세 배율 렌더·원호 채움 비율/모션·원형 리사이즈·네이티브 이동 메시지·포인터 누적 이동/탈출·스크롤 바 드래그/트랙 클릭·실제 GPU 카운터·번들 폰트·최소/기본 창 크기에서의 버튼 대비를 포함한 UI 검증 301건을 수행합니다. 렌더 PNG와 결과는 `artifacts/qa`에 저장됩니다.

실제 Windows 창에서 위젯 생성, 제목 드래그 이동, 모서리 드래그에 따른 Big 그래프 및 Small 전환, 최소 크기의 메뉴 접근, 그룹 상속, 중복 실행, 정상 종료와 저장을 확인했습니다. 실제 모니터의 화면 배율 전환, 보조 모니터 제거, 절전 복귀, Win+D, 트레이 메뉴의 모든 동작 조합은 별도 수동 검증 항목입니다. CPU 지원 검증 범위는 논리 프로세서 64개 이하입니다. 상세 기록은 `VALIDATION.md`에 있습니다.

설치 프로그램, 자동 시작 등록, 자동 업데이트, 바탕화면 Explorer 부착, 그룹 단위 이동은 포함하지 않습니다.
